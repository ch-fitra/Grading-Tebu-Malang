# Model grading tebu v0.0.1

Bobot lokal: `v0.0.1.sugarcane.keras`. Runtime menggunakan Keras dengan backend PyTorch. Input RGB 224 x 224, piksel 0-255; layer rescaling berada di model, sehingga jangan menormalisasi dua kali. Logits diproses dengan softmax sesuai config.json.

| Indeks | Kode output |
|---|---|
| 0 | A |
| 1 | B |
| 2 | D |
| 3 | G |
| 4 | M |
| 5 | T |

Enam kode ini adalah kontrak teknis model. S dan X ada pada UI/database, tetapi bukan keluaran langsung model enam kelas ini. Arti operasional, rafaksi dan keputusan giling harus dicocokkan dengan label dataset serta SOP QC Malang. Deskripsi lama yang menafsirkan M sebagai kurang baik tidak konsisten dengan panduan UI dan tidak dijadikan dasar keputusan baru.

Bobot tidak diganti dalam pemisahan instalasi Malang. Uji eksekusi model tidak membuktikan akurasi pada sudut kamera Malang; validasi dengan gambar lapangan diperlukan.
