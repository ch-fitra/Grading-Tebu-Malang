# 📄 Dokumentasi Model: `v0.0.1.sugarcane.keras`

## 📌 Deskripsi & Spesifikasi Model
Model ini adalah model AI Klasifikasi Kualitas Tebu berbasis Keras/TensorFlow yang dilatih untuk menilai tingkat mutu tebu secara otomatis.

* **Nama Model:** `v0.0.1.sugarcane.keras`
* **Format File:** Keras Model Format (`.keras`)
* **Arsitektur Model:** Single Image Classification (Single Label Output)
* **Jumlah Dataset Training:** ± 1.200 Data Gambar Tebu
* **Jumlah Kelas Output:** 6 Kelas (`A`, `B`, `D`, `G`, `M`, `T`) + *Support Kelas `S` pada database*

---

## 🏷️ Rincian Kelas & Indeks Pembacaan
| Indeks Output | Kode Kelas | Deskripsi Mutu Tebu |
| :---: | :---: | :--- |
| **0** | **`A`** | Mutu Tebu Grade A (Bersih / Sangat Baik) |
| **1** | **`B`** | Mutu Tebu Grade B (Baik) |
| **2** | **`D`** | Mutu Tebu Grade D (Sedang) |
| **3** | **`G`** | Mutu Tebu Grade G (Banyak Kotoran / Trash Tinggi) |
| **4** | **`M`** | Mutu Tebu Grade M (Kurang Baik) |
| **5** | **`T`** | Mutu Tebu Grade T (Terganggu / Sampah / Terbakar) |

> **Catatan Tambahan:**  
> Kelas **`S` (Super / Ultra Clean)** disiapkan di tingkat Database (`sugarcane_ai`) untuk mendukung skalabilitas versi model masa depan, meskipun pada versi `v0.0.1` ini model baru mendeteksi 6 kelas utama (0 s/d 5).

---

## ⚙️ Spesifikasi Input & Konfigurasi Engine
* **Ukuran Input Gambar:** `224 x 224` pixel
* **Warna Input:** RGB, rentang 0–255. File model memiliki layer `Rescaling(1/255)` internal; jangan membagi piksel dengan 255 lagi sebelum inferensi.
* **Aktivasi Output:** Layer akhir model menghasilkan 6 logits (`Dense`, aktivasi `linear`). Engine menerapkan Softmax melalui `output_activation: "softmax"`.
